# Third-party components

The MIT license applies to GlyphLink's own source and assets. Third-party components retain their own licenses. This project is not affiliated with Nothing, Evolution X, Google or Microsoft.

The finished installer includes CPython, Tcl/Tk, CustomTkinter, NumPy, Pillow, PyStray, SoundCard and supporting packages, Microsoft Visual C++ runtime files and Android SDK platform-tools. Their original license, notice and package metadata files remain in the payload where supplied. See release/dependencies.txt for the component inventory.

NSIS compiles the Windows launchers. The Android companion uses Android framework APIs and the Evolution X Glyph adapter interface. The external Glyph service is not bundled by this project.
